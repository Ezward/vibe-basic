================================================================================
VIBE BASIC LANGUAGE SPECIFICATION: GRAMMAR, SEMANTICS, AND EXAMPLES
================================================================================

I. EBNF GRAMMAR
--------------------------------------------------------------------------------
(* Note: All keywords and identifiers are case-insensitive. *)

(* Structure *)
program         = { line } ;
line            = line_number statement { ":" statement } newline ;
line_number     = digit { digit } ;

(* Statements *)
statement       = let_stmt | print_stmt | if_stmt | goto_stmt | input_stmt |
                  for_stmt | next_stmt | gosub_stmt | return_stmt |
                  def_fn_stmt | data_stmt | read_stmt | restore_stmt |
                  dim_stmt | erase_stmt | remark | end_stmt ;

let_stmt        = [ "LET" ] variable [ "(" expression { "," expression } ")" ]
                  "=" expression ;
print_stmt      = "PRINT" [ print_list ] ;
if_stmt         = "IF" expression "THEN" then_clause [ "ELSE" then_clause ] ;
then_clause     = line_number | statement ;
goto_stmt       = "GOTO" line_number ;
input_stmt      = "INPUT" [ string_literal ( ";" | "," ) ] variable ;
for_stmt        = "FOR" variable "=" expression "TO" expression
                  [ "STEP" expression ] ;
next_stmt       = "NEXT" [ variable ] ;
gosub_stmt      = "GOSUB" expression ;
return_stmt     = "RETURN" [ expression ] ;
def_fn_stmt     = "DEF" "FN" identifier [ "(" identifier { "," identifier } ")" ]
                  "=" expression ;
data_stmt       = "DATA" data_item { "," data_item } ;
data_item       = number | string_literal | identifier ;
read_stmt       = "READ" variable { "," variable } ;
restore_stmt    = "RESTORE" [ line_number ] ;
dim_stmt        = "DIM" array_decl { "," array_decl } ;
array_decl      = variable "(" expression { "," expression } ")" ;
erase_stmt      = "ERASE" variable { "," variable } ;
remark          = ( "REM" | "'" ) { character } ;
end_stmt        = "END" ;

(* Print list *)
print_list      = print_item { print_item } ;
print_item      = expression | ";" | "," ;

(* Expressions — listed from lowest to highest precedence *)
expression      = or_expr ;
or_expr         = xor_expr { "OR" xor_expr } ;
xor_expr        = and_expr { "XOR" and_expr } ;
and_expr        = not_expr { "AND" not_expr } ;
not_expr        = "NOT" not_expr | comparison ;
comparison      = additive { comp_op additive } ;
comp_op         = "=" | "<>" | "<" | ">" | "<=" | ">=" ;
additive        = term { ( "+" | "-" ) term } ;
term            = power { ( "*" | "/" ) power } ;
power           = unary { "^" unary } ;
unary           = "-" unary | factor ;
factor          = number | string_literal | "(" expression ")"
                | function_call | variable ;
function_call   = identifier "(" [ expression { "," expression } ] ")" ;

(* Terminals *)
variable        = identifier [ "$" | "%" | "!" | "#" ] ;
identifier      = letter { letter | digit | "_" } ;
number          = digit { digit } [ "." { digit } ] ;
string_literal  = '"' { character } '"' ;
letter          = "A" | ... | "Z" | "a" | ... | "z" ;
digit           = "0" | ... | "9" ;


II. SEMANTIC EXPLANATIONS
--------------------------------------------------------------------------------
1. LET (Assignment)
   Action: Evaluates the expression on the right and stores the result in the
   memory location associated with the variable. The "LET" keyword is optional;
   a bare variable assignment (e.g., X = 5) is treated as an implicit LET.
   Note: String variables (ending with $) must receive string values.

2. PRINT (Output)
   Action: Sends data to the screen.
   - A semicolon (;) suppresses spacing between items.
   - A comma (,) moves the cursor to the next 14-character tab zone.
   - A trailing semicolon or comma suppresses the newline at end of line.
   - PRINT with no arguments outputs a blank line.

3. INPUT (Data Entry)
   Action: Pauses the program and displays a "? " prompt. It waits for the user
   to type a value and press ENTER before assigning that value to the variable.
   An optional prompt string followed by ";" or "," may precede the variable name.
   When a semicolon is used, a "? " is automatically appended to the prompt.
   When a comma is used, the question mark is suppressed.
   String variables (ending with $) receive the input as a string; numeric
   variables attempt to parse the input as a number.

4. GOTO (Branching)
   Action: Changes the Program Counter to the specified line number. This is
   the primary method for creating loops or jumping over sections of code.

5. IF...THEN...ELSE (Conditional)
   Action: Evaluates an expression. If truthy (non-zero for numbers, non-empty
   for strings), it executes the clause after THEN. If falsy and an ELSE clause
   is present, it executes the ELSE clause. If falsy and no ELSE clause is
   present, it skips the remaining statements on the current line.
   Both THEN and ELSE may target either a line number (implicit GOTO) or an
   inline statement.

6. FOR / NEXT (Iteration)
   Action: Automates a counted loop. FOR sets the loop variable to a start
   value and specifies an end limit and optional STEP increment (default 1).
   NEXT increments the counter by the step value and loops back to the line
   after FOR until the limit is exceeded. Nested FOR/NEXT loops are supported.
   If the initial value already exceeds the limit (respecting STEP direction),
   the loop body is skipped entirely.

7. GOSUB / RETURN (Subroutines)
   Action: GOSUB branches to a subroutine beginning at the line number given by
   the expression argument. Before jumping, the interpreter pushes the return
   address (the statement immediately following the GOSUB) onto an internal
   stack. RETURN pops the most recent return address from the stack and resumes
   execution there. GOSUB calls may be nested to arbitrary depth; each RETURN
   matches the most recent unmatched GOSUB. Issuing RETURN without a preceding
   GOSUB produces a "RETURN without GOSUB" error.
   The target is an expression, so it may be a literal line number or a variable:
     GOSUB 500        — branch to subroutine at line 500
     GOSUB BASE + 100 — branch to a computed line number
   RETURN may optionally take an expression argument that evaluates to a line
   number. When provided, RETURN still pops the subroutine stack but jumps to
   the specified line number instead of the stacked return address:
     RETURN           — resume at the statement after the most recent GOSUB
     RETURN 500       — pop the stack, then jump to line 500
     RETURN BASE + 10 — pop the stack, then jump to a computed line number
   On a multi-statement line, RETURN resumes at the next statement after the
   GOSUB on the calling line, not at the next line:
     10 GOSUB 100 : PRINT "AFTER"   — PRINT executes after RETURN

8. REM (Remark)
   Action: Ignored by the interpreter. Used for human-readable notes. Both the
   REM keyword and the apostrophe (') syntax consume the rest of the line.

9. DEF FN (User-Defined Functions)
   Action: Defines a named, single-line function. The function name must begin
   with FN (e.g., FNMUL). Parameters in the parameter list are local to the
   function and do not affect variables of the same name elsewhere. The function
   body is a single expression. The definition must be executed before the
   function is called. To return a string, use a $ suffix on the name (FNGET$).
   Example: DEF FNMUL(A, B) = A * B
   Calling: result = FNMUL(10, 5)

10. END (Termination)
    Action: Stops program execution immediately.

11. DIM (Array Dimensioning)
    Action: Allocates storage for one or more arrays and establishes maximum subscript
   values. Each dimension's maximum subscript is specified in the parentheses; since
   subscripts start at 0, the actual size of each dimension is max_subscript + 1.
   All elements are initialized to zero (numeric) or empty string (string arrays).
   Multiple arrays may be dimensioned in a single DIM statement, separated by commas.
   An array cannot be re-dimensioned without first using ERASE.
   If an array variable is used without a DIM statement, it is automatically dimensioned
   with a maximum subscript of 10 in each dimension referenced.
   Example: DIM A(20)  — creates a 21-element array (indices 0 to 20).
   Example: DIM B(3, 4)  — creates a 4×5 two-dimensional array.

12. ERASE (Array Removal)
    Action: Removes one or more arrays from the program, freeing their storage.
    After ERASE, an array may be re-dimensioned with DIM. Erased arrays lose all
    stored values; after re-dimensioning, all elements are initialized to zero.
    Example: ERASE A, B

13. Expressions
   Operator precedence (lowest to highest):
     - Logical OR:  OR
     - Logical XOR: XOR
     - Logical AND: AND
     - Logical NOT: NOT (unary)
     - Comparison:  =  <>  <  >  <=  >=
     - Additive:    +  -
     - Multiplicative:  *  /
     - Exponentiation:  ^
     - Unary:       - (negation)
   All binary operators are left-associative.
   Comparison operators return -1 for true and 0 for false (MS-BASIC style).
   Logical operators (AND, OR, XOR, NOT) operate as bitwise integer operations.
   Since comparisons return -1 (all bits set) for true and 0 for false, logical
   operations work correctly for boolean logic: NOT 0 = -1, NOT -1 = 0,
   -1 AND -1 = -1, -1 OR 0 = -1, -1 XOR -1 = 0.
   The + operator performs string concatenation when both operands are strings.
   String comparison is supported with all comparison operators.

14. Built-in Functions
    Numeric Functions:
    - INT(x)   — Returns the floor of x (rounds toward negative infinity).
    - ABS(x)   — Returns the absolute value of x.
    - SQR(x)   — Returns the square root of x.
    - RND(x)   — Returns a random number in [0.0, 1.0). The argument is
                  required but its value is ignored (MS-BASIC compatibility).
    - EXP(x)   — Returns e raised to the power of x.
    - LOG(x)   — Returns the natural logarithm of x (x must be positive).
    - SGN(x)   — Returns the sign of x (1 for positive, 0 for zero, -1 for negative).
    - SIN(x)   — Returns the sine of x (x in radians).
    - COS(x)   — Returns the cosine of x (x in radians).
    - TAN(x)   — Returns the tangent of x (x in radians).
    - ATN(x)   — Returns the arctangent of x in radians.
    - FIX(x)   — Returns the integer part of x (truncates toward zero).
    - CINT(x)  — Rounds x to the nearest integer.
    - CSNG(x)  — Converts x to single-precision.
    - CDBL(x)  — Converts x to double-precision.

    String / Substring Functions:
    - LEN(s$)  — Returns the length of string s$.
    - LEFT$(x$, n)  — Returns the first n characters from string x$.
    - RIGHT$(x$, n) — Returns the last n characters from string x$.
    - MID$(x$, n [, m]) — Returns a substring starting at position n
                  (1-based). If m is given, returns at most m characters;
                  otherwise returns everything from position n to the end.
    - INSTR([n,] x$, y$) — Returns the 1-based position of the first
                  occurrence of y$ in x$, or 0 if not found. Optional n
                  specifies the starting search position.

    Conversion Functions:
    - ASC(x$)  — Returns the ASCII code of the first character of x$.
    - CHR$(n)  — Returns the character with ASCII code n.
    - STR$(x)  — Converts number x to its string representation (positive
                  numbers include a leading space).
    - VAL(x$)  — Converts string x$ to a number (returns 0 if non-numeric).
    - HEX$(x)  — Converts number x to an uppercase hexadecimal string.
    - OCT$(x)  — Converts number x to an octal string.

    Formatting and Creation Functions:
    - STRING$(n, x$) — Returns a string of n copies of the first character
                  of x$. STRING$(n, m) uses the character with ASCII code m.
    - SPACE$(n) — Returns a string of n spaces.
    - SPC(n)   — Returns n spaces (for use in PRINT statements).
    - TAB(n)   — Returns n spaces (simplified; for use in PRINT statements).

    Binary/Random File Data Functions:
    - MKI$(x)  — Converts integer x to a 2-byte string (little-endian).
    - MKS$(x)  — Converts single-precision x to a 4-byte string.
    - MKD$(x)  — Converts double-precision x to an 8-byte string.
    - CVI(x$)  — Converts a 2-byte string back to an integer.
    - CVS(x$)  — Converts a 4-byte string back to single-precision.
    - CVD(x$)  — Converts an 8-byte string back to double-precision.

15. Variables
    Variable names may contain letters, digits, and underscores, and must
    start with a letter. Names are case-insensitive and stored uppercase.
    An optional type sigil at the end indicates the variable type:
      $  string,  %  integer,  !  single-precision,  #  double-precision.

16. Array Variables
    Arrays store multiple values under a single variable name, accessed by one
    or more numeric subscripts. Subscripts are zero-based: the first element
    is at index 0.

    Declaring arrays:
      DIM A(20)       — creates a 1-D array with indices 0 through 20 (21 elements).
      DIM B(3, 4)     — creates a 2-D array (4 rows × 5 columns), indices
                        0..3 and 0..4.
      DIM C(2, 3, 4)  — creates a 3-D array with indices 0..2, 0..3, and 0..4.
      DIM A(5), B(10) — multiple arrays may be declared in one DIM statement.

    String arrays use the $ sigil: DIM N$(10) declares a string array.

    Default dimensioning:
      If a subscripted variable is used without a prior DIM, it is automatically
      dimensioned with a maximum subscript of 10 in each dimension referenced.
      For example, X(5) auto-creates a 1-D array with indices 0 through 10.

    Initialization:
      All numeric array elements are initialized to 0. All string array
      elements are initialized to the empty string "".

    Accessing elements:
      Array elements may appear anywhere a scalar variable can:
        A(3) = 42           — assignment (with or without LET)
        PRINT B(1, 2)       — in expressions
        X = A(I) + A(J)     — computed subscripts
        READ A(I)            — as a READ target
        INPUT A(I)           — as an INPUT target

    Re-dimensioning:
      An array cannot be re-dimensioned unless it is first removed with ERASE.
      Attempting DIM on an already-dimensioned array produces an error.
        ERASE A              — removes array A
        ERASE A, B           — removes multiple arrays at once
      After ERASE, the array may be re-dimensioned with DIM. All values from
      the previous allocation are lost; new elements are initialized to zero.

    Limits:
      Arrays may have up to 255 dimensions.
      Subscript values must be non-negative integers. Accessing a subscript
      beyond the declared maximum produces a "Subscript out of range" error.

17. Multi-statement Lines
    Multiple statements may appear on a single line, separated by colons (:).


III. CODE EXAMPLES AND OUTPUT
--------------------------------------------------------------------------------

EXAMPLE 1: USER INTERACTION
Code:
10 PRINT "WHAT IS YOUR NAME?"
20 INPUT N$
30 PRINT "HELLO "; N$; "!"
40 END

Output:
WHAT IS YOUR NAME?
? ALICE
HELLO ALICE!

EXAMPLE 2: CONDITIONAL MATH
Code:
10 LET X = 5
20 INPUT "GUESS (1-10): "; G
30 IF G = X THEN PRINT "CORRECT!" ELSE PRINT "WRONG, IT WAS"; X
40 END

Output:
GUESS (1-10): 5
CORRECT!

EXAMPLE 3: THE FOR-NEXT LOOP
Code:
10 PRINT "POWERS OF 2:"
20 FOR I = 1 TO 5
30   PRINT 2 ^ I;
40 NEXT I
50 END

Output:
POWERS OF 2:
2 4 8 16 32

EXAMPLE 4: NESTED LOOPS
Code:
10 FOR I = 1 TO 2
20   FOR J = 1 TO 2
30     PRINT I; J;
40   NEXT J
50   PRINT
60 NEXT I
70 END

Output:
 1  1  1  2
 2  1  2  2

EXAMPLE 5: BUILT-IN FUNCTIONS
Code:
10 PRINT "INT(3.7) ="; INT(3.7)
20 PRINT "ABS(-5) ="; ABS(-5)
30 PRINT "SQR(9) ="; SQR(9)
40 PRINT "RANDOM:"; INT(RND(1) * 100)
50 PRINT "LEN ="; LEN("HELLO")
60 END

Output:
INT(3.7) = 3
ABS(-5) = 5
SQR(9) = 3
RANDOM: 42
LEN = 5

EXAMPLE 6: GOSUB / RETURN
Code:
10 FOR I = 1 TO 3
20   N = I
30   GOSUB 100
40 NEXT I
50 END
100 REM — FACTORIAL SUBROUTINE (N! -> RESULT)
110 RESULT = 1
120 FOR J = 2 TO N
130   RESULT = RESULT * J
140 NEXT J
150 PRINT N; "! ="; RESULT
160 RETURN

Output:
 1 ! = 1
 2 ! = 2
 3 ! = 6

EXAMPLE 7: MULTI-STATEMENT LINE AND IMPLICIT LET
Code:
10 X = 0 : Y = 10
20 PRINT X; Y
30 END

Output:
 0  10
